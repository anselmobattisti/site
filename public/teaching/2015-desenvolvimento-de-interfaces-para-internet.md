# Desenvolvimento de Interfaces para Internet

- Semester 2015
- Institution UNIVEL
- Programme Tecnologia em Análise e Desenvolvimento de Sistemas (TADS)
- Level Undergraduate
- Hours 75 h
- Language pt-BR

## Syllabus

Estudo da história e conceitos sobre a Internet. Caracterização da Linguagem de Marcação de Hipertexto (HTML). Compreensão da Linguagem de Estruturação (XML) e Linguagem XHTML. Estudo e desenvolvimento dos conceitos de Web Design com Folhas de Estilo em Cascata (CSS); noções básicas de programação e validações no lado cliente com JavaScript e noções básicas de programação no lado servidor com PHP.

## Recommended reading

- CARDOSO, Mádel. Desenvolvimento web para o ensino superior. Rio de Janeiro: Axcel Books, 2004.
- CASTRO, Elisabeth ; SENKO, José Jorge . HTML 4 para a world wide web. 1. ed. São Paulo: Makron Books, 2000. 534 p.
- CHOI, Wankyu et al. Beginning PHP 4: programando. São Paulo: Makron Books, 2001. 719 p.
